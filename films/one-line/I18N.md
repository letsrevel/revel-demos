# I18N — one set of files, several languages

The film renders in English and German from the same compositions.

## How a language is selected
`bash tools/build.sh <lang>` regenerates `index.html` for that language (a HyperFrames
project has exactly one root). It loads `data/timing.<lang>.js`, so in every layer
`FILM.T.lang` is `'en'` or `'de'`, and `FILM.T.lines` are that language's lines with that
take's spoken word times. Audio, sound design and the credit ("Stimme: Tobias
Fischbach") follow automatically.

## Rules for every scene layer
1. **No hard-coded visible text.** Every visible string comes from a small dictionary at
   the top of the layer's script, keyed by language:
   `const L = { en: {...}, de: {...} }[FILM.T.lang] || {...en}`.
   Set text from it at build time (before `revealWords`). English stays exactly as it is now.
2. **Voice-synced lines show exactly the spoken line.** Take the text from
   `FILM.line(id).text` (or the dictionary, if it equals that text), so
   `FILM.revealWords` maps word *i* on screen to spoken word *i*. To show part of a line,
   pass `{ from, to }` word indexes. Never assume English word counts or positions.
3. **No English words in timing lookups.** `FILM.wordAt('v06', 'read')` breaks in German.
   Use word indexes looked up per language (`{ en: 3, de: 5 }`), or a per-language word
   (`{ en: 'read', de: 'lesen' }`). The same goes for any constant derived from English word
   times: compute it from `FILM.wordAt` at build time instead.
4. **German copy**:
   - **Revel UI strings:** use the real ones from
     `~/repos/letsrevel/revel-frontend/messages/de.json` wherever the screen mimics a
     Revel screen (buttons, chips, labels).
   - **Address and inclusive forms:** Revel's German uses **du** and gender stars
     (Teilnehmer*innen, Käufer*innen).
   - **Numbers:** `18,00 €`, `2,49 €`.
   - **Quotation marks:** „…".
   - **Apostrophe:** ’.
   - **Proper names stay:** "Intro to Shibari — Rope & Trust", "Shibari Circle Vienna",
     "The Velvet Cellar", "Basement Sessions — Live & Loud", Noa Beckmann, Ren. Cities in
     German: Wien, Graz, Linz, Salzburg, Innsbruck.
5. **German runs longer.** Check every frame for overflow and wrapping. Keep 80 px safe
   margins. Shrink type a step if a label doesn't fit; never let text touch an edge or
   collide.
6. **Tagline (DE), verbatim, the website's wording:** „Die kostenlose, quelloffene
   Event-Plattform für Communities, Vereine und unabhängige Veranstaltungsorte." The
   main take said "Clubs … Spielstätten"; the voice is the Draft 03 pickup (2026-10-14).
